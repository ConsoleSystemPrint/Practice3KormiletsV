# Практическая работа № 6 — Профиль

TheMealDB на Kotlin и Compose. Профиль с ФИО, аватаром и ссылкой на резюме сохраняется в JSON-файле. Фото выбирается из галереи или снимается камерой и копируется в память приложения. Резюме скачивается и открывается через FileProvider; для PDF предусмотрен встроенный просмотрщик. Используются MVVM, Clean Architecture и DI.

[Демонстрация профиля](artifacts/practice6/profile-demo.mp4). Проверено на Android 12L и Android 17. В записи имя вводится как `Kormilets Viacheslav Aleksandrovich`; ссылка ведёт на демонстрационный PDF.
