# Практическая работа № 3 Кормилец Вячеслав Александрович РИ-430948

TheMealDB: список из 12 рецептов с фотографиями, поиск по названию, фильтры по категории, кухне и ингредиенту, подробная карточка блюда и избранное. Нижняя навигация переключает три экрана.

Single Activity, Jetpack Compose, MVVM, StateFlow, Navigation Compose и ConstraintLayout. По заданию используются локальные моковые данные без сетевых запросов и пагинации. Подготовленные URL TheMealDB содержат тестовый ключ `1` в пути и параметр `key=1`.
