# Практическая работа № 4 Кормилец Вячеслав Александрович РИ-430948

TheMealDB: загрузка рецептов и фотографий, поиск по названию, фильтры по категории, кухне и ингредиенту, карточка блюда и избранное. Есть состояния загрузки, ошибок и повтор запроса.

Jetpack Compose, MVVM, Clean Architecture (data/domain/ui), Retrofit, Coroutines, StateFlow и Coil. Запросы кэшируются в памяти, «Обновить» обращается к серверу. Тестовый ключ `1` передаётся в пути и `key=1`. В debug-сборке подключён Chucker.
