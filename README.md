# Практическая работа № 5 — TheMealDB

Android-приложение с рецептами, поиском и фильтрами. Настройки отдельного экрана сохраняются в DataStore; общий DI-кэш управляет бейджем активных настроек. Избранное хранится в Room, фотографии — в памяти устройства: рецепты доступны без интернета. Используется KSP.

Демонстрации: [сохранение настроек](artifacts/practice5/settings-persistence.mp4), [избранное без интернета](artifacts/practice5/favorites-offline.mp4).
