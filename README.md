# Лабораторная № 7 Многомодульность

TheMealDB на Kotlin и Compose. Профиль с ФИО, аватаром из галереи или камеры и скачиванием резюме вынесен в самостоятельный модуль. Сохраняются MVVM, Clean Architecture и DI.

- `app` — приложение, рецепты и подключение профиля к общей навигации.
- `feature:profile` — экраны профиля и редактора, ViewModel, бизнес-логика, хранение, фотографии и просмотр резюме.
- `core:ui` — общая тема, состояния загрузки и ошибки, общие иконки.

Зависимости: `app → feature:profile → core:ui`, также `app → core:ui`. Новые модули не зависят от `app`.
